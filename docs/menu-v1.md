# Menu v1

Третій повністю перенесений модуль Tiflis v2.

## Дані

- 315 legacy-позицій перенесені з одного JSON у нормалізовану таблицю `menu_items`;
- 40 категорій збережені без перейменування;
- старий `settings.menu_items` залишений як rollback-знімок;
- підтримані фото, ціна, вага, опис, алергени, звичайний і піковий час приготування;
- додані канонічні поля `emoji`, `stopped`, `sort_order`, `updated_at`;
- додані унікальність та індекси для каталогу й стоп-листа.

## Робочий інтерфейс

- пошук по назві, категорії, опису та алергенах;
- секції й категорії з лічильниками;
- режим завантаженої кухні для показу пікового часу;
- окрема фільтрація стоп-позицій;
- картки з фото або emoji-fallback;
- детальна картка позиції;
- швидке додавання/зняття зі стопу;
- повний редактор позиції для шефа й адміністрації;
- адаптивні мобільні bottom sheets.

## Права

- читання: будь-який активний працівник із доступом до модуля;
- стоп-лист: `admin`, `sysadmin`, `chef`, `cook`;
- створення, редагування та видалення: `admin`, `sysadmin`, `chef`;
- усі записи проходять через окремий JWT-захищений `tiflis-menu-api`.

## Відкинуті рудименти

- один 50-тисячний JSON як база меню;
- глобальні `onclick` та HTML-рядки;
- localStorage як джерело істини;
- окрема дубльована модель спрощеного меню;
- неіснуюче поле `stopped` у старому modular store.
