# Tiflis v2 — активна міграція завершена

`tiflisv2/main` є єдиним активним кодом порталу.

## Перенесені робочі області

- захищений вхід і Supabase Auth;
- головна та щоденний operations workspace;
- графік;
- каса та рейтинг;
- меню і стоп-лист;
- резерви;
- персонал і життєвий цикл акаунтів;
- управління, оголошення, права та аудит.

## Серверні домени

- `tiflis-auth-migrate`;
- `tiflis-secure-api`;
- `tiflis-menu-api`;
- `tiflis-reserve-api`;
- `tiflis-staff-api`;
- `tiflis-admin-api`;
- `tiflis-operations-api`.

## Джерело істини

- браузер не зберігає робочі паролі;
- дані читаються й змінюються через Supabase та JWT-захищені доменні API;
- legacy JSON лишається лише rollback snapshot там, де це було потрібно для міграції;
- vanilla-код збережений у гілці `archive/vanilla-v2`, але не входить до активного runtime.

## Свідомо не перенесені рудименти

- імпорт графіка з фото;
- обміни змінами;
- drag-and-drop порядку працівників;
- Telegram-спам після кожної дрібної зміни;
- localStorage як джерело істини;
- глобальні onclick та HTML templates;
- показ або редагування чинних паролів;
- hard-delete працівників;
- автоматичне видалення резервів через дві доби.
