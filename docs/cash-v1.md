# Cash v1

Другий повністю перенесений модуль Tiflis v2.

## Збережена робоча логіка

- щоденна каса та чайові;
- незмінний `first_cash` для чесного рейтингу каси;
- доплати з коротким поясненням;
- розрахунок виплати окремо за 1–14 та 15–кінець місяця;
- формула: 4% каси + 200 ₴ за робочий день + доплати;
- місячний топ каси;
- рейтинг персоналу від −100 до +100 з короткими коментарями.

## Покращення v2

- один послідовний екран замість набору вкладених legacy-панелей;
- календар щоденних внесень;
- окреме відображення чайових, без змішування із зарплатою;
- приховування сум інших працівників для неадміністраторів;
- серверна перевірка `user_id`, дат, сум і ролей;
- адміністративне перемикання між працівниками;
- адаптивні bottom sheets для редагування на мобільному;
- рейтинг каси показує працівникам позицію, але не чужі суми.

## Відкинуті рудименти

- localStorage-кеш як джерело істини;
- фоновий polling із гонками запису;
- дубльовані сторінки топів;
- ручна синхронізація кількох локальних структур;
- inline HTML та глобальні onclick-обробники.
