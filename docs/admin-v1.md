# Admin v1

Шостий базовий модуль Tiflis v2 та завершення первинної міграції основної навігації.

## Зони управління

- огляд production-метрик;
- активність модулів і доменних Edge Functions;
- публікація повідомлень у портал;
- опційна Telegram-розсилка за ролями;
- typed-конфіг порталу;
- глобальний банер та maintenance flag;
- стан Auth-only міграції;
- безпечне знищення legacy-паролів уже пов’язаних акаунтів;
- read-only матриця ролей і прав;
- журнал адміністративних дій.

## Дані

- `portal_config` — одна типізована конфігурація замість довільного JSON;
- `audit_log` — append-only історія адміністративних операцій;
- прямий доступ браузера до обох таблиць закритий RLS та revoke;
- усі записи виконуються через service role всередині JWT-захищеного API.

## Серверна архітектура

- окремий `tiflis-admin-api`;
- доступ лише для `admin` і `sysadmin`;
- жодні секрети, токени або паролі не повертаються клієнту;
- публікація повідомлення створює audit entry;
- зміни конфігурації створюють audit entry;
- очищення прострочених повідомлень створює audit entry;
- credential scrub зачіпає лише акаунти, що вже мають `staff_profiles`.

## Відкинуті рудименти

- дублювання керування персоналом в адмінці;
- редагування ACL як довільного JSON у браузері;
- перегляд або ручне введення чинних паролів;
- змішування Telegram, персоналу, меню та всіх налаштувань в одному монолітному файлі;
- небезпечні кнопки очищення всієї бази;
- localStorage як джерело адміністративних налаштувань.
