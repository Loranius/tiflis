# Бот Тифлісу в робочому чаті

Бот `@tiflis_vinn_bot` у групі команди відповідає на команди (меню з'являється після `/`).
Спека: `docs/superpowers/specs/2026-11-23-telegram-group-bot-design.md`.

## Як підключити

1. Додай бота в робочий чат. Якщо його додав адмін порталу (з привʼязаним Telegram), чат
   вмикається одразу; інакше адмін порталу пише в чаті `/enable`.
2. Дай боту права адміністратора: тоді він бачить усі повідомлення і запамʼятовує всіх, хто пише.
3. Кухні та всім, кого немає на порталі, адмін призначає роль: відповідає на повідомлення
   людини командою `/role кухар` (`/role -` — прибрати ручну роль).

## Команди

| Команда | Що робить |
|---|---|
| `/all` | Згадує всіх у чаті |
| `/waiters` `/kitchen` `/bar` `/hostess` `/admins` | Згадує відділ |
| `/today` | Хто сьогодні на зміні (графік порталу) |
| `/best` | Найкращий офіціант дня (один на день) |
| `/horoscope` | Гороскоп за знаком із порталу (один на день) |
| `/birthdays` | Три найближчі дні народження |
| `/stop` | Стоп-лист меню |
| `/roles` | Хто є хто |
| `/role <роль>` | Призначити роль (адмін, відповіддю) |
| `/help` | Довідка |

«Усі в чаті» — це ті, кого бот бачив у чаті, плюс користувачі порталу з привʼязаним Telegram,
чиє членство в чаті підтверджує Telegram (бот не може отримати повний список учасників).

## Як влаштовано

- Функція `supabase/functions/tiflis-telegram-bot` — єдиний вебхук бота (Telegram дозволяє один).
  Вона сама обробляє групові повідомлення і `my_chat_member`; усе інше (особисті повідомлення,
  `/start` для привʼязки акаунта, кнопки підтверджень) без змін пересилає старій функції
  `quick-responder`.
- Запити Telegram перевіряються заголовком `X-Telegram-Bot-Api-Secret-Token` (похідне від токена).
- Таблиці: `telegram_chats`, `telegram_chat_members`, `telegram_daily_picks` (RLS, лише сервер).
- Службові дії (заголовок `x-cron-secret`): `{"action":"info"}`, `{"action":"setup","url":…}`,
  `{"action":"restore"}` — повернути вебхук на `quick-responder` (відкат).
