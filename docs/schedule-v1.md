# Schedule v1

Перший повністю перенесений модуль нового Tiflis v2.

## Реалізовано

- місячна таблиця з навігацією між місяцями;
- вкладки підрозділів з підтримкою другої ролі працівника;
- збереження наявного порядку рядків із legacy settings;
- режим команди та персональний режим «Мій рядок»;
- sticky-заголовки, sticky-колонка працівників і виділення поточного дня;
- адаптивний mobile bottom-sheet для вибору зміни;
- optimistic UI, індикатор збереження та автоматичний rollback при помилці;
- серверні `schedule_bootstrap` і `schedule_upsert` через JWT-захищений `tiflis-secure-api`;
- адміністратор редагує всю таблицю, працівник — лише свій рядок відповідно до ACL;
- production-сумісність із реальною схемою `schedule(user_id, date, shift)` без залежності від неіснуючої `shift_types`.

## Наступні ітерації

- пакетне імпортування графіка з фото після окремої перевірки AI-пайплайна;
- обміни змінами;
- drag-and-drop порядку працівників із серверним збереженням;
- журнал змін та агреговані сповіщення без спаму.
